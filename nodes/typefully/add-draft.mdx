This node allows you to programmatically add content as a draft in Typefully, ideal for automating content creation workflows—like generating threads via AI and queuing them for review and scheduling.

## Features

Our Add Draft to Typefully integration provides:

- Simple text-based draft creation
- Support for multi-thread drafts (future: structured thread input)
- Seamless workflow integration (e.g., after AI content generation)
- Drafts appear ready for editing, preview, and scheduling in the Typefully app

## Available Operations

Create Draft Post
- Add a new draft with your provided content.

Key Capabilities:

- Handles plain text up to 10,000 characters (Twitter limits in mind)
- Auto-saves as a single post or thread starter
- Includes metadata like creation timestamp
- No publishing—stays in drafts for manual approval

## Configuration

| Parameter       | Type    | Description                                    |
| --------------- | ------- | ---------------------------------------------- |
| postContent | Textarea  | The full text of the draft post or thread. |

Tips for postContent:

- Keep under 280 chars per tweet segment for easy splitting.
Use Markdown-like formatting (bold, italics) for preview rendering in Typefully.

## Example Usage

### Basic Single Post Draft

```json
{
 "postContent": "Excited to share my latest workflow hack using Svalync! Automate your day in minutes. #NoCode #Automation"
}
```

## Response Format

```json
{
  "response": {
    "status": "created | failed",
    "draft_id": "string",
    "title": "string (auto-generated from first line)",
    "content_preview": "string (first 100 chars)",
    "web_url": "string",
    "created_at": "datetime (ISO 8601)",
    "error": "string (if failed)"
  }
}
```


## Error Handling
Common error scenarios:

- Invalid content: 400 "Content too short (>10 chars required)"
- Auth expired: 401 "Reconnect Typefully account"
- Rate limit: 429 "Too many drafts—wait 1 minute"
- Account limits: 403 "Upgrade Typefully plan for more drafts"
