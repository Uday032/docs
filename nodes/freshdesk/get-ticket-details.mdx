This node pulls everything—subject, description, status, priority, requester info, custom fields, attachments, and conversation history—perfect for AI agents, workflow automation, or building smart dashboards.

## Features

Our Get Ticket Details from Freshdesk integration provides:

- Full ticket metadata including custom fields
- Includes attachments, tags, and conversations
- Real-time sync with Freshdesk
- Supports private notes and agent replies
- Works across all Freshdesk plans

## Available Operations

Fetch Ticket by ID
- Retrieve a complete ticket record.
Key Capabilities:

- Returns up to 100 conversation threads
- Includes file attachments with URLs
- Respects field-level permissions

## Configuration

| Parameter       | Type    | Description                                    |
| --------------- | ------- | ---------------------------------------------- |
| ticketId | String | The numeric ID of the ticket (found in URL or list). |


## Best Practices

- Always validate availability before booking
- Use Find → Filter → Book chain in workflows
- Send confirmation via email/SMS after booking
- Add to CRM (e.g., Attio, HubSpot) post-booking
- Use webhooks to trigger follow-ups (e.g., prep email 1h before)

## Error Handling
Common error scenarios:

- Slot taken: 409 — "Time no longer available"
- Invalid email/phone: 400 — "Validation failed"
- Event disabled: 403 — "Booking not allowed"
- Auth error: 401 — "Invalid API key or token"
