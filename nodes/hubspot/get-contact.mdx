---

This node pulls all standard and custom properties, lifecycle stage, engagement history, and associations (e.g., companies, deals).

## Features

- Full contact profile with custom fields
- Includes email, phone, lifecycle stage, owner
- Returns associated records (company, deals)
- Real-time data from HubSpot CRM
- Works with all HubSpot plans

## Available Operations

Fetch Contact by ID
- Get a single contact using its unique HubSpot ID.

## Configuration

| Parameter       | Type    | Description                                    |
| --------------- | ------- | ---------------------------------------------- |
| **contactId** | String | The HubSpot Contact ID (numeric). |


## Best Practices

- Always validate availability before booking
- Use Find → Filter → Book chain in workflows
- Send confirmation via email/SMS after booking
- Add to CRM (e.g., Attio, HubSpot) post-booking
- Use webhooks to trigger follow-ups (e.g., prep email 1h before)

## Example Usage

### Get Contact Details

```json
{
  "contactId": "987654321"
}
```

## Error Handling
Common error scenarios:

- Contact not found: 404 — "Contact does not exist"
- Invalid ID: 400 — "Invalid contact ID format"
- Auth failed: 401 — "Invalid token or scopes"
- Rate limit: 429 — "Too many requests"
