This node fetches details like subject, status, priority, timestamps, and associated data (e.g., requester, attachments)—ideal for monitoring, reporting, or triggering follow-up actions in workflows.

## Features

Our Get Ticket Details from ZohoDesk integration provides:

- Full ticket metadata including custom fields
- Optional inclusion of related resources (e.g., comments, attachments)
- Secure access to sensitive ticket data
- Real-time syncing with Zoho Desk

## Available Operations

Retrieve Ticket by ID
- Fetch details for a single ticket using its unique ID.

Key Capabilities:

- Includes dynamic fields based on your Zoho Desk setup
- Supports up to 1MB response size
- Handles attachments and tags

## Configuration

| Parameter       | Type    | Description                                    |
| --------------- | ------- | ---------------------------------------------- |
| ticketId | String  | The unique ID of the ticket to retrieve. |


## Example Usage

### Basic Ticket Fetch

```json
{
 "ticketId": "903000000000099"
}
```

```json

    "ticket_number": "string",

    "description": "string",

    "department_id": "string",
    "requester_id": "string",
    "assignee_id": "string",
    "created_time": "string (ISO 8601)",
    "modified_time": "string (ISO 8601)",
    "tags": ["string"],
    "attachments": [
      {
        "id": "string",
        "file_name": "string",
        "file_size": "number",

}
```


## Error Handling
Common error scenarios:

- Ticket not found: 404 "Ticket does not exist"
- Unauthorized: 401 "Invalid OAuth token"
- Forbidden: 403 "Lacks Desk.tickets.READ scope"
- Rate limit: 429 "Too many requests—retry in 60s"
- Server error: 500 "Temporary issue; retry later"
